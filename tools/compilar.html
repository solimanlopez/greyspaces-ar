Compilar targets.mind

Genera el archivo de seguimiento a partir de las cartelas. Se ejecuta entero en el navegador, no sube nada a ningún sitio.

  1. Elige las imágenes de targets/compilar/ en orden alfabético (A, B, C, D). Ese orden tiene que coincidir con el array MARCADORES de js/config.js.
  2. Pulsa compilar y espera.
  3. Guarda el archivo resultante como targets/targets.mind.
